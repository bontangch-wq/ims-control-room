# IMS Control Room

Integrated Management System Control Room for ISO 9001, ISO 14001, ISO 45001, SMK3, SMKP Minerba and ISO/IEC 17025.

## Runtime
Next.js + Neon PostgreSQL + Neon Auth.

Production secrets such as `DATABASE_URL` must be configured in the hosting environment and are never committed to this repository.
